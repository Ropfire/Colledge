## Запуск

Откройте терминал VS Code в папке практической.
`python -X utf8 exercises.py` выполняет задания 1–6: encoding_lab/texts/student.txt
с двумя русскими строками; profile.txt с именем, группой и собственной фразой;
чтение и сравнение; encode/decode строк из задания; первые 20 байтов profile.txt.

`python -X utf8 main.py` создаёт encoding_check/note.txt с тремя собственными
русскими строками, читает файл, проверяет совпадение, показывает первые 20 байтов
и результаты utf-8/latin-1. Дополнение encoding_check/extra.txt содержит другой
русский текст: выводятся количество символов строки и количество байтов файла.
Все пути строятся от Path.cwd(), а не от расположения исходника.

Запись и чтение явно используют encoding="utf-8" и newline="\n".
Физические окончания строк — LF даже в Windows; поэтому read_bytes().decode()
совпадает с исходной строкой без нормализации CRLF. Кириллица занимает несколько
байтов на символ в UTF-8, поэтому число байтов больше числа символов.
latin-1 может декодировать любые байты, но не восстанавливает исходный русский текст.
Повторный запуск заново записывает только собственные учебные файлы и даёт те же байты.

## Паузы для скриншотов

`python -X utf8 main.py --pause` ожидает Enter перед записью; после создания note.txt;
после чтения/декодирования; после дополнения extra.txt.
`python -X utf8 exercises.py --pause` останавливается перед созданием;
после создания student/profile; после проверки profile; после encode/decode.
Можно открыть текстовый файл в VS Code во время паузы.
Обе программы имеют функцию `main(pause=False)` для неинтерактивного запуска.

## Проверка

`python -B -X utf8 -m unittest discover -s tests -v`

Тесты работают во временной папке: проверяются русские строки, имя и группа,
точные UTF-8 байты без CRLF, результаты обоих декодирований, длины, повторный
запуск, отрицательное сравнение и паузы.

## План и проверка

План: сверить PDF; написать явное UTF-8 чтение/запись; добавить учебный и итоговый
сценарии; проверить точные байты и повторы через unittest.
При самопроверке учтено различие LF/CRLF в Windows, иначе сравнение строки
с декодированными байтами могло бы зависеть от платформы.
Полный код main.py предназначен для включения в Word-отчёт.

## Комплект сдачи и ограничение

Отчёты Word/PDF включают итоговый код, таблицу фактических наблюдений,
ответы на контрольные вопросы и вывод. В outputs сохранены реальные журналы
первого и повторного запусков и результаты unittest.
Скриншоты выполнения не включены: управление окнами остановлено по просьбе
пользователя. Текстовые журналы не заменяют обязательные скриншоты по методичке;
для полного соответствия их нужно добавить позднее. Искусственные снимки не создавались.
