## Запуск

Рабочей папкой терминала VS Code должна быть папка этой практической.
`python -X utf8 exercises.py` выполняет задания 1–6 в `Path.cwd()/file_lab`:
incoming/notes.txt копируется в backup/notes_backup.txt;
incoming/data.txt переименовывается в incoming/measurements.txt,
затем переносится в ready/measurements.txt.

`python -X utf8 main.py` выполняет самостоятельную работу в workspace_ops:
incoming/task.txt копируется в backup/task_backup.txt;
incoming/config.txt переименовывается в incoming/settings.txt,
затем переносится в ready/settings.txt. incoming/draft.txt остаётся на месте.
Дополнение: incoming/memo.txt переименовывается в incoming/memo_final.txt.
Каждый исходный файл содержит две строки. Все пути строятся от Path.cwd().

## Безопасность и повторный запуск

Перед действием проверяются источник (обычный файл), отсутствие целевого пути
и существование целевого каталога. Конфликт, отсутствующий источник или ошибка
ОС дают сообщение и False, а не аварийное завершение. После успешного действия
выводятся оба exists() и результат проверки. Функции safe_copy, safe_rename,
safe_move и create_source доступны для отдельных проверок.

Начальная подготовка использует режим x, а не w: уже существующие файлы
не перезаписываются. Источник не воссоздаётся, если обнаружен промежуточный
или конечный путь цепочки; поэтому повторный запуск не создаёт config.txt,
settings.txt, memo.txt заново. Даже если исходник для копирования отсутствует,
но копия уже есть, новый исходник не создаётся. Защита рассчитана на обычный
последовательный учебный запуск, а не на конкурентную работу нескольких процессов.

## Скриншоты и фазы

`python -X utf8 main.py --pause` ожидает Enter после подготовки исходной
структуры (до операций), после копирования, после переименования,
после перемещения, после дополнения memo, после итогового списка.
У `exercises.py --pause` те же остановки, кроме дополнения memo.
Функция `main(pause=False)` работает без интерактивного ввода.
Для исходных скриншотов нужно запускать в новой пустой рабочей папке.
Программа сама ничего не удаляет и не сбрасывает предыдущий результат.

## Тестирование

`python -B -X utf8 -m unittest discover -s tests -v`

Тесты используют TemporaryDirectory. Проверяются итоговая структура и две строки,
повторы без изменения пользовательских данных, неизменность целей при конфликтах,
пропавшие источники, каталоги вместо файлов, отсутствующая целевая папка,
безопасная начальная подготовка и число интерактивных фаз.

## План и проверка

План: сверить PDF; реализовать проверяемые безопасные функции;
собрать учебный и итоговый сценарии; запустить unittest.
При самопроверке отдельно учтён риск перезаписи при начальном создании:
проверка только перед copy/rename/move была бы недостаточна.
Полный код main.py предназначен для включения в Word-отчёт.

## Комплект сдачи и ограничение

Отчёты Word/PDF включают итоговый код, таблицу фактических наблюдений,
ответы на контрольные вопросы и вывод. В outputs сохранены реальные журналы
первого и повторного запусков и результаты unittest.
Скриншоты выполнения не включены: управление окнами остановлено по просьбе
пользователя. Текстовые журналы не заменяют обязательные скриншоты по методичке;
для полного соответствия их нужно добавить позднее. Искусственные снимки не создавались.
