# Практическая №3 — Работа с каталогами

Студент: Зыков Егор Тимурович, ИСиП-23-1. Среда: Python 3.x, VS Code.
Зависимости: только стандартная библиотека Python.

## Запуск

В терминале VS Code откройте именно папку этой практической.
Команда `python -X utf8 exercises.py` выполняет задания 1–8 в `Path.cwd()/practice40`.
Команда `python -X utf8 main.py` выполняет итоговую работу в `Path.cwd()/workspace`.

`practice40` содержит materials/theory.txt (две строки), reports/result.txt
(две строки) и logs/session.log (одна строка). Итоговая структура содержит также
пустой temp и самостоятельное дополнение notes/readme.txt.
Программа выводит полный путь, exists/is_dir/is_file, непосредственное содержимое
с метками и подсчёты файлов и каталогов. Копирование, перемещение,
переименование и удаление не используются. Существующие файлы не перезаписываются.

## Фазы для скриншотов

`python -X utf8 main.py --pause`: Enter запрашивается перед созданием workspace,
после анализа основной структуры и после добавления notes/readme.txt.
У `exercises.py --pause` три остановки: перед созданием, после создания,
после классификации. Для получения исходных фаз выбирайте новую пустую рабочую
папку; расположение файлов определяется рабочим каталогом, а не расположением скрипта.
Обе функции `main(pause=False)` можно вызывать из Python без ввода.

## Проверка

`python -B -X utf8 -m unittest discover -s tests -v`

Тесты создают только временные каталоги и проверяют структуру, строки,
подсчёты, повторный запуск без изменения файлов, отсутствующий каталог и паузы.

## План и проверка

План: сверить PDF; реализовать учебную и итоговую структуры; проверить unittest.
При самопроверке учтено, что iterdir() не рекурсивен, а повторный запуск не должен
портить изменённые учебные файлы. Проверка выполняется в изолированных каталогах.
Полный текст кода main.py предназначен для включения в Word-отчёт.

## Комплект сдачи и ограничение

Отчёты Word/PDF включают итоговый код, таблицу фактических наблюдений,
ответы на контрольные вопросы и вывод. В outputs сохранены реальные журналы
первого и повторного запусков и результаты unittest.
Скриншоты выполнения не включены: управление окнами остановлено по просьбе
пользователя. Текстовые журналы не заменяют обязательные скриншоты по методичке;
для полного соответствия их нужно добавить позднее. Искусственные снимки не создавались.

Git не хранит пустые каталоги: workspace/temp создаётся программой после
клонирования. В него намеренно не добавлен .gitkeep, чтобы не менять результат
учебного анализа файловой структуры.
